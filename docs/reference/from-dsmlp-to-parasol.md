# From DSMLP to PARASOL

PARASOL is the platform formerly called DSMLP, and research work on it was
formerly called the Research Cluster. If you used the platform or Datahub
before, you do not need to do anything: your account, your files and your
commands work as before.

<!-- former names: begin -->

| At a glance | |
|---|---|
| What you need to do | Nothing |
| Login node | `dsmlp-login.ucsd.edu` |
| Reservation app | [reserve.dsmlp.ucsd.edu](https://reserve.dsmlp.ucsd.edu/) |
| Support | [parasol@ucsd.edu](mailto:parasol@ucsd.edu), research work included |

## What Stays the Same

| You use | It is still |
|---|---|
| Datahub in a browser | [datahub.ucsd.edu](https://datahub.ucsd.edu), with your UC San Diego sign-in |
| The login node | `dsmlp-login.ucsd.edu` |
| The reservation app | [reserve.dsmlp.ucsd.edu](https://reserve.dsmlp.ucsd.edu/) |
| Launch scripts | `launch.sh`, `launch-scipy-ml.sh`, and the other launch commands, with the same flags |
| Your files | The same home directories, shared workspace space, and datasets |
| Workspaces and quotas | The same course, lab, and project workspaces, with the same limits |
| The ITS Service Desk | [support.ucsd.edu](https://support.ucsd.edu/) |
| Research IT, for research work | [rcd-support@ucsd.edu](mailto:rcd-support@ucsd.edu), alongside [parasol@ucsd.edu](mailto:parasol@ucsd.edu) |
| Policy | The same conditions of use, in [Policy](policy.md) |

> [!NOTE]
> **You will still see the old name**
> Hostnames, container labels, and system messages still say `dsmlp`. Command
> output on the cluster also uses the old name. Both names refer to the same
> platform.

## What Changes

| What | Now |
|---|---|
| The name | Course pages, syllabi, and support replies will say PARASOL. Older material that says DSMLP is still correct. |
| The support address | Questions about the platform go to [parasol@ucsd.edu](mailto:parasol@ucsd.edu). |
| Research work | Research that ran as the Research Cluster is part of PARASOL, on the same cluster, with the same tools and support as instruction. Coursework comes first in [peak weeks](policy.md#peak-gpu-demand). Questions go to [parasol@ucsd.edu](mailto:parasol@ucsd.edu), and Research IT also answers them at [rcd-support@ucsd.edu](mailto:rcd-support@ucsd.edu). |
| The documentation | Every page of the DSMLP documentation is on this site too, at the same address and in the same place in the navigation. |

## Where the Old Documentation Went

Each page of the DSMLP documentation has a matching page here, at the same
address and under the same heading in the navigation. Three are titled for
PARASOL:

| DSMLP documentation | PARASOL page |
|---|---|
| DSMLP and Datahub Overview | [How PARASOL Works](../overview.md) |
| Teaching with DSMLP and Datahub | [Teaching with PARASOL and Datahub](../instructor-or-ta.md) |
| Research on DSMLP | [Research on PARASOL](../individual-researcher.md) |

When the DSMLP documentation site is retired, each of its addresses will
forward to the same address here, so course materials that link to the old
addresses keep working.
